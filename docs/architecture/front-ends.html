One metric layer, any front end

Sources land in the warehouse through dlt, and every metric is defined once in dbt with MetricFlow. On top of that one layer the front end is a choice: a live Claude dashboard for small teams, Lightdash for self-serve BI, or dbt Charts boards rendered from the marts.
